# PHAROS AAAI-27 Ready Package

This package converts the PHAROS NeurIPS-style draft into an AAAI-27 anonymous submission package.

Files:
- `main.tex` — AAAI-27 anonymous main paper source. Requires official AAAI-27 author-kit style files.
- `references.bib` — BibTeX references.
- `supplementary.tex` — appendices moved out of the main paper.
- `OpenReview_fields.txt` — title, abstract, and keywords for abstract registration.
- `AAAI_reproducibility_checklist_guidance.md` — checklist guidance.
- `AAAI_guideline_checklist.md` — compliance checklist.
- `PHAROS_AAAI27_Submission_Draft.pdf` — generated preview PDF for review, not a replacement for official AAAI compilation.

Important:
Use the official AAAI-27 Author Kit from the AAAI website/venue page for final compilation. This package is structured to use `aaai27.sty`.
